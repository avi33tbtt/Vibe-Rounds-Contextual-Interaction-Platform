
# Synthetic example: hypertension follow-up

This example illustrates the contracts, not a clinical protocol. The questions and thresholds are illustrative only and must be reviewed by qualified clinicians before any real use.

Flow:
1. A mock pathway declares that home blood pressure, medication adherence, and symptoms are required.
2. CIP checks the authorized context summary.
3. Missing or stale elements produce a collection task.
4. A collection specification guides a patient form or chatbot.
5. The response envelope preserves patient-reported provenance.
6. A mock EMR validates and decides whether to accept or review the proposed observations.

No real patient data is included.
